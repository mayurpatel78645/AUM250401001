Core Java Practice Programs

## 📌 Overview

This project contains 15 Java programs covering fundamental programming concepts, including:

* Basic logic and number manipulation
* Loops and conditional statements
* Recursion
* Pattern printing
* Method overloading
* Clean modular design

All programs are organized using packages and executed through a single `Main` runner class.

## 🚀 Features

* Single `Scanner` instance managed in `Main`
* Modular package separation (`basic` and `pattern`)
* Reusable logic (e.g., Pyramid reused for Diamond)
* Method overloading (Palindrome for String and Number)
* Iterative and recursive implementations (Factorial)
* Efficient mathematical approaches (Armstrong, Sum of Digits)
